🤖 Self-Learning AI Agent Using Python

A simple AI agent that learns to navigate a grid environment using Reinforcement Learning and the Q-Learning algorithm.

Features

- Learns through trial and error.
- Avoids obstacles.
- Uses rewards and penalties.
- Saves learned knowledge using a Q-table.

Technologies

- Python
- Reinforcement Learning
- Q-Learning
- VS Code

How to Run

python main.py

Learning Outcomes

- AI fundamentals
- Machine Learning
- Autonomous decision-making
- Q-Learning algorithm
